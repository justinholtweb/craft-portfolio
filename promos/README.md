# Plugin Store promo images

Marketing images for the Portfolio listing on the Craft Plugin Store, rendered in the same theme as
the plugin's marketing page at
[justinholt.com/plugins/craft-portfolio](https://justinholt.com/plugins/craft-portfolio).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `portfolio-promo-N.jpg`, 1920×1080 (rendered at 2× in headless Chrome,
then downsampled and converted in one `sips` pass). Promos ship as JPEG, never PNG. If `sips`
fails intermittently the PNG is left in `out/`; rerun the slide, and check `out/` holds only
`.jpg` files before calling the deck done.

## Editing

Everything lives in `slides.html` — one `<section class="slide">` per image. The palette and fonts
are the plugin site's: accent `#93348C` (plum), Jersey 20 for display, Inter for body.

`assets/` holds the fonts and two icon files:

- `icon.svg` — the app icon, used for the cover mark and the footer lockup. Copy it from
  `../src/icon.svg` whenever the icon changes.
- `watermark.svg` — only the two peaks from the picture in the icon's tallest tile. The tiles are
  large flat rectangles and the sun lands behind the content panels as a grey disc, so both are
  left out.

`shots/` holds real control-panel captures. Retake them from the plugin-testing harness when the
CP changes.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.

The price on slides 1 and 7 is one of the places pricing lives — see the pricing list in the
justinholt `plugin-marketing-site` skill before changing it.
