Roles, not handles

Rename a field.
Nothing breaks.

Templates ask for a role. The plugin looks the field up by UID at the moment it is asked.

  • The same templates work on a section you adopt (Pro)
  • Untick a role and everything skips it
{# every project for one client, in one category #} {% for item in craft.portfolio.items({ client: 'Harbor Co.', category: 'branding' }).all() %} {{ item|portfolioField('summary') }} {% endfor %} {{ craft.portfolio.next(entry).url }} {{ craft.portfolio.related(entry, 3)|length }}
